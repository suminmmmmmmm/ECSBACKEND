Eye-Can-Speak

아이 트래킹 기반 루게릭병 환자 의사소통 보조 서비스


------------------------------------------------

📖 Project Overview


루게릭병 환자는 질병이 진행됨에 따라
신체 움직임과 발화 기능이 점진적으로 제한되지만,
눈의 움직임은 비교적 오래 유지되는 특성이 있습니다.

본 프로젝트는 이러한 특성에 주목하여
아이 트래킹(Eye Tracking) 기술을 활용한 의사소통 보조 서비스를 설계·구현하였으며,
환자가 최소한의 신체 움직임만으로도 의사를 표현할 수 있도록 돕는 것을 목표로 합니다.

| 구분              | 담당       |
| --------------- | -------- |
| **백엔드**         | 김수민, 강수민 |
| **프론트엔드**       | 노경미      |
| **AI 및 아이 트래킹** | 한시진, 문현지 |

### **주요 기능**

1. **아이트래킹 키보드**
- 사용자의 눈동자 움직임을 감지하여 화면 조작 및 기타 작업
- 동공 추적을 활용하여 키보드 입력 기반 의사소통
- DB를 활용한 사용자 맞춤 자동완성 기능
1. **루게릭병 환자들을 위한 커뮤니티 (작성/수정/삭제)**
- 질병에 대한 정보를 공유함으로써 본인의
치료방향이나 향후 대처 방향을 잡는데 도움을 줄 수 있다.

### **담당 기능**
    
    1️⃣ 게시판 도메인 API 전체 설계 및 구현
    
    - 게시글 CRUD API 구현
    
    →   루게릭병 환자와 보호자들이 질환 정보, 생활 경험을 공유할 수 있도록 게시판 기반 커뮤니티 기능을 설계
    
    - 게시글 생성 / 수정 / 삭제 / 단건 조회 / 전체 조회(로그인한 회원만 기능 사용 가능)
    - 페이지네이션 기반 목록 조회 API 설계
    
    - 게시글 이미지 업로드 처리
        - multipart/form-data 기반 이미지 업로드
        - AWS S3 연동 및 이미지 메타데이터 DB 저장
        - 게시글 수정 시 기존 이미지 유지 / 추가 / 삭제 로직 구현
    - 게시글 **키워드 검색 API 구현
    
    ---
    
    2️⃣ 사용자 인터랙션 기능 구현 (Like · Scrap)
    
    - 게시글 좋아요 / 좋아요 취소 API 구현(토글)
        - 중복 좋아요 방지
        - 사용자별 좋아요 상태 관리
    - 내가 좋아요한 게시글 조회 API 구현(토글)
    - 게시글 스크랩 기능 구현
        - 스크랩 추가 / 삭제
        - 스크랩한 게시글 전체 조회 API
    
    ---
    
    3️⃣ 댓글 · 대댓글 시스템 구현
    
    - 댓글 작성 / 삭제 / 조회 API 구현
    - 대댓글(부모–자식 구조) 설계
        - JPA 연관관계 기반 댓글 계층 구조 구현
    - 내가 작성한 댓글 조회
    - 댓글 단 게시글 조회 API 구현
- aws EC2 배포 /  S3 (이미지) /  RDS
    - AWS EC2
        - Spring Boot 서버 배포
        - Linux 환경에서 서비스 운영
    - AWS RDS (PostgreSQL)
        - 운영 DB 구성 및 서버 연동
    - AWS S3
        - 게시글 이미지 저장소로 활용
        - 서버와 S3 간 업로드/삭제 연동 처리
